# Projetos SmallBasic
Nesse repositório estão armazenados os meus primeiros projetos. Foram desenvolvidos no _Small Basic_, uma plataforma desenvolvida pela _Microsoft_ em 2008, destinada a iniciantes na programação, e com uma linguagem própria de mesmo nome.

Meu primeiro projeto foi o [FruitSelector](projetos/concluidos/-%20FRUIT%20SELECTOR%20-/), um programa simples criado com apenas duas semana de estudo, e desenvolvido ao longo do tempo. O sistema é uma loja virtual fictícia onde o usuário compra frutas e realiza pagamento fictício.

![Captura de tela do FruitSelector II](projetos/concluidos/-%20FRUIT%20SELECTOR%20-/Capturas/Imagem%20B.png)

O último sistema arquitetado por mim na plataforma foi o [Laser ao Alvo](projetos/concluidos/-%20Laser%20ao%20Alvo%20-/), um jogo onde o usuário controla uma nave, representada por um paralelepípedo, que atira lasers em alvos no fim de um corredor. O projeto inteiro foi desenvolvido usando _perspectiva 3D_, dando ilusão de profundidade. Contava também com tutorial, upgrades, personalização, menu, e muitos outros sistemas integrados.

Outro projeto importante que eu fiz foi o [Sandbox of Squares](projetos/concluidos/-%20Sandbox%20of%20Squares%20-/), onde se pode desenhar na tela usando quadriláteros. Eu me esforcei para dá o máximo de _liberdade ao usuário_ e criei um _sistema de personalização_. O jogo conta com: sistema de redimencionamento de janela, tutorial, borracha, sistema de configurações, cores, grossura de linha, e muito mais.
